# NEXUS — Future & Innovation Summit

A modern, fully responsive event management website for a fictional technology and innovation summit.

## Tech Stack
HTML5, CSS3, vanilla JavaScript. No frameworks or build tools required.

## Features
- Responsive hero, events, experience, venue and pass sections
- Six event cards with unique abstract CSS artwork
- Search and category filtering
- Detailed event pop-ups
- Registration with required name, email, 10-digit phone, event and pass
- JavaScript and native HTML form validation
- Confirmation screen
- Local Storage registration data (`nexusRegistrations`)
- Dark/light mode with saved preference
- Live countdown to 21 August 2027, 9:00 AM IST
- Mobile menu and CSS motion

## Run
Open `index.html` directly in a modern browser, or use VS Code Live Server.

## Deployment
Push `index.html`, `style.css`, `script.js` and `README.md` to a GitHub repository.
Import the repository into Vercel as an **Other** framework static site, or use GitHub Pages/Netlify.

## Disclaimer
All event names, schedule details, location, and prices are fictional. Registrations are stored in the current browser only. This project does not process real tickets or payments.
